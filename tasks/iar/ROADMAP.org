# i.ar Roadmap

No dates. Dependencies and ordering only. Completion is implicit: if a task directory exists, it's not done. If it's gone (removed via remove_task), it's done.

## Alpha Goal

i.ar alpha = the platform works for both the long-term-plan track (concept library, life-org) AND the pentesting track. Feature freeze is in effect. No new features enter the roadmap without explicit rejection of alternatives. New ideas go to future_ideas.md.

**After the current roadmap is complete:** One final assessment pass to verify all alpha capabilities are implemented. Then the next roadmap is the long-term plan integration (concept library authoring, degree summarization, life-org workflows).

## Cycle Guidelines for Continuous Agents

When working autonomously:
1. read_roadmap to get this file
2. Walk Phase 1 in step order. For each step, read_task on the path to check if it still exists
3. If the task directory exists, it's not done -- work on it
4. If the task directory is gone, it's done -- move to the next step
5. One task per cycle. Small, deliberate changes.
6. When a task is complete: remove_task, log to HISTORY.log, end with LOOP_COMPLETE
